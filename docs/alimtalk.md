# 알림톡 설정 가이드

진행 상황(신청 접수, 입금 확인, 수거, 배송 등)을 고객에게 **카카오 알림톡**으로 자동으로 보냅니다. 알림톡이 실패하면 같은 내용을 **문자**로 보냅니다. 새 신청과 새 문의는 운영자 휴대폰으로 **문자**가 갑니다.

설정 전에도 앱은 정상 동작합니다. 보내지 못한 알림은 관리자 주문 상세의 **알림 발송** 칸에 "안 보냄"과 이유로 남습니다.

발송은 [솔라피(SOLAPI)](https://solapi.com)를 씁니다. 다른 업체로 바꾸려면 `src/lib/notify/solapi.ts`만 바꾸면 됩니다.

## 준비 순서

알림톡은 카카오 심사가 필요해서 며칠 걸립니다. 1~3번을 먼저 시작해 두세요.

1. **사업자등록**: 알림톡을 보내려면 사업자등록증이 있는 비즈니스 채널이어야 합니다. 홈택스에서 개인사업자로 온라인 신청할 수 있습니다.
2. **카카오톡 채널 만들기 → 비즈니스 채널 신청**
   - [카카오비즈니스](https://business.kakao.com)에서 채널을 만들고 **비즈니스 채널 신청**에 사업자등록증을 올립니다.
   - 채널 **홈 공개**를 켜고 **고객센터 전화번호**를 입력합니다. 빠지면 연동 단계에서 실패하는 경우가 많습니다.
   - 1:1 채팅은 꺼 두어도 됩니다. 문의는 앱 안 문의하기로 받습니다.
3. **솔라피 가입**
   - 발신번호(본인 휴대폰)를 등록하고 인증합니다. 대체 문자와 운영자 문자에 씁니다.
   - **카카오 채널 연동**: 연동하면 `PF`로 시작하는 발신 프로필 ID(pfId)가 생깁니다.
   - **알림톡 템플릿 등록**: 아래 템플릿을 하나씩 등록하고 검수를 신청합니다. 본문은 **한 글자도 바꾸지 말고** 그대로 붙여 넣으세요. 다르면 발송이 실패합니다.
   - 검수가 끝나면 템플릿마다 `KA`로 시작하는 템플릿 ID가 생깁니다.
   - **API 키 발급**: API Key와 API Secret을 만듭니다.
4. **Netlify 환경 변수** 추가 후 다시 배포 (Deploys → Trigger deploy)

   | 변수 | 값 |
   |---|---|
   | `SOLAPI_API_KEY` | 솔라피 API Key |
   | `SOLAPI_API_SECRET` | 솔라피 API Secret |
   | `SOLAPI_PFID` | 카카오 채널 연동으로 생긴 `PF...` |
   | `SOLAPI_SENDER` | 솔라피에 등록한 발신번호 (예: `010-1234-5678`) |
   | `SOLAPI_TEMPLATES` | 템플릿 ID 목록. 예: `ORDER_RECEIVED=KA01TP...,PAID=KA01TP...,PICKED_UP=KA01TP...` |
   | `ADMIN_PHONE` | 새 신청·문의 문자를 받을 운영자 휴대폰 |
   | `APP_URL` | 알림에 넣을 앱 주소. 예: `https://battery119.netlify.app` |

   `SOLAPI_TEMPLATES`에 없는 알림은 보내지 않고 기록만 남깁니다. 검수가 끝난 것부터 하나씩 추가해도 됩니다.

5. **발송 확인**: 직접 신청을 하나 넣고, 관리자 주문 상세 **알림 발송** 칸에 "보냄"이 뜨는지 확인합니다. "실패"면 옆에 솔라피가 돌려준 이유가 나옵니다.

## 검수에서 알아둘 점

- 모두 고객이 신청한 주문의 진행 상황을 알리는 **정보성 메시지**라 알림톡 용도에 맞습니다. 쿠폰·할인 같은 광고 문구는 넣지 마세요. 넣으면 검수에서 떨어집니다.
- 본문의 `#{링크}`는 변수로 된 주소입니다. 검수에서 링크를 변수로 쓸 수 없다고 하면, 템플릿에 **웹링크 버튼**을 추가하고 본문에서 `#{링크}` 줄을 빼는 방식으로 바꿔야 합니다. 이 경우 코드도 함께 바꿔야 하니 알려 주세요.
- 템플릿 본문을 고치려면 `src/lib/notify/templates.ts`를 고친 뒤 `node scripts/build-alimtalk-doc.mjs`로 이 문서를 다시 만들고, 바뀐 템플릿은 다시 검수받으세요.

### 수리 신청 접수 (`ORDER_RECEIVED`)

```
[파크리오 배터리 119] 수리 신청 접수

#{동호} 고객님, 수리 신청이 접수됐어요.

■ 주문번호: #{주문번호}
■ 제품: #{제품}
■ 결제 금액: #{금액}
■ 입금 계좌: #{계좌}

#{수거안내}
진행 상황은 아래 주소에서 확인하실 수 있어요.
#{링크}
```

### 견적 안내 (`QUOTE_READY`)

```
[파크리오 배터리 119] 견적 안내

#{동호} 고객님, 신청하신 제품의 견적이 나왔어요.

■ 주문번호: #{주문번호}
■ 제품: #{제품}
■ 결제 금액: #{금액}
■ 입금 계좌: #{계좌}

#{수거안내}
#{링크}
```

### 입금 확인 및 수거 안내 (`PAID`)

```
[파크리오 배터리 119] 입금 확인

#{동호} 고객님, #{금액} 입금이 확인됐어요.

■ 수거일: #{수거일} 저녁 7~10시
제품을 박스에 포장해서 문 앞에 두세요.
#{링크}
```

### 수거 완료 (`PICKED_UP`)

```
[파크리오 배터리 119] 수거 완료

#{동호} 고객님, #{제품} 제품을 수거했어요.
배터리 진단 후 교체를 시작하고, 진행 상황을 다시 알려 드릴게요.
#{링크}
```

### 교체 완료 및 배송 안내 (`DELIVERY_SCHEDULED`)

```
[파크리오 배터리 119] 교체 완료 · 배송 안내

#{동호} 고객님, 배터리 교체와 품질검사를 마쳤어요.

■ 배송일: #{배송일} 저녁 7~10시
문 앞으로 가져다 드릴게요.
#{링크}
```

### 교체 불가 및 환불 안내 (`RETURN_SCHEDULED`)

```
[파크리오 배터리 119] 교체 불가 · 환불 안내

#{동호} 고객님, 죄송하지만 #{제품} 제품은 배터리 교체가 어려워요.

■ 환불 금액: #{금액}
■ 반송일: #{배송일} 저녁 7~10시
제품은 문 앞으로 돌려드려요.
#{링크}
```

### 배송 완료 (`DELIVERED`)

```
[파크리오 배터리 119] 배송 완료

#{동호} 고객님, 교체한 제품을 문 앞에 두었어요.

■ 보증 기간: #{보증종료}까지
같은 증상이 다시 생기면 앱에서 무상 재점검을 요청해 주세요.
#{링크}
```

### 신청 취소 (`CANCELED`)

```
[파크리오 배터리 119] 신청 취소

#{동호} 고객님, 주문 #{주문번호} 신청이 취소됐어요.
#{환불안내}
```

### 문의 답변 등록 (`INQUIRY_ANSWERED`)

```
[파크리오 배터리 119] 문의 답변

#{동호} 고객님, 남겨 주신 문의에 답변이 등록됐어요.
앱에서 확인해 주세요.
#{링크}
```

### 로그인 비밀번호 재설정 (`PIN_RESET`)

```
[파크리오 배터리 119] 로그인 비밀번호 재설정

#{동호} 로그인 비밀번호가 새로 설정됐어요.

■ 새 비밀번호: #{비밀번호}
로그인한 뒤 내 정보에서 비밀번호를 바꿔 주세요.
#{링크}
```

#{링크}
